# Open Midnight Commander Here service menu

This service menu works similarly to my previous service *Scan with ClamAv*, but it is
dedicated to launch the Midnight Commander file manager in a Yakuake or Konsole session.
Similarly to the former service, the provided actions allow to open Midnight Commander
within the current or a new session (Konsole and Yakuake) or reusing one of the opened
instances (Konsole).

## Features

These are the *Open Midnight Commander Here* service menu features:

- Licensed under the GPL-v3 license;
- Fully translated into 5 languages besides English
  (French, German, Italian, Portuguese, Spanish);
- Works from within the Dolphin, Konqueror, Krusader, and KFind results context menu;
- Support for KDE Plasma 6;
- Browse with Midnight Commander the selected folders within the current or a new session (Konsole or Yakuake);
- Browse with Midnight Commander the selected folders within the first or last terminal instance (Konsole).

## Requirements

- KDE 4 or superior;
- KDialog;
- qtpaths6 for Plasma 6;
- Midnight Commander;
- Qt D-Bus;
- Konsole or Yakuake.

## Install

To keep the latest stable version installed, updated, and easily removed from the same interface,
it is recommended to install this service menu through *Dolphin*:

- From Settings > Context Menu > Download new services;
- Search for *Open Midnight Commander Here*;
- Click on the *Install* button.

Also, the *Discover* application can install it:

- Under Application Addons > Servicemenu;
- Search for: *Open Midnight Commander Here*;
- Click on the *Install* button.

For debugging purpose follow one of the other methods mentioned on the [project page][installation].
